# unearthed
CodePath Unit 1 Lab: UnEarthed is a crowdsourced repo of great gift ideas for different kinds of people. Browse gifts by intended audience, price point, or category, or upload your own gift ideas.

CodePath unit 2 Lab: UnEarthed creates a Postgres database that hooks up to the UnEarthed web app. The fronted code is modified to accept information from the gifts table in the database.
